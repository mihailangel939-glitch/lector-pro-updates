# Лист Про — обновления

Готовые подписанные обновления переносимой читалки для Windows x64.

[Скачать последний выпуск](https://github.com/mihailangel939-glitch/lector-pro-updates/releases/latest)

Книги, закладки и настройки сохраняются в существующей папке Data. Закройте читалку перед применением обновления.

Для версий 0.4.35 и ниже без настроенного GitHub-доступа один раз установите обновлятор 0.4.36 вручную. Дальше читалка проверяет новые версии автоматически, без аккаунта и токена.

В этом репозитории размещаются только README и готовые файлы выпусков. Исходный проект хранится отдельно в приватном репозитории. Скачивать обновления может любой; загружать выпуски — только участники с правом записи.
