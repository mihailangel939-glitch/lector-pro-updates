# Лист Про

Читалка для Windows 10/11 x64. Готовые файлы доступны без GitHub-входа.

## Первая установка

[Скачать установщик 0.4.36](https://github.com/mihailangel939-glitch/lector-pro-updates/releases/download/v0.4.36/List-Pro-Setup-0.4.36.exe)

Запустите установщик, выберите папку и при желании создайте ярлык. Права
администратора, Node.js и PowerShell не нужны. В комплекте читалка, Tor и Calibre.
Дополнительный нейросетевой модуль Docling с моделями в этот пакет не включён.

## Обновление существующей читалки

[Скачать обновлятор 0.4.36](https://github.com/mihailangel939-glitch/lector-pro-updates/releases/download/v0.4.36/ListPro-Update-0.4.36.exe)

Закройте читалку обычным способом и обновите её существующую папку. Книги,
закладки, настройки и кэш остаются в `Data`, без переноса в другую библиотеку.
С версии 0.4.36 новые обновления находятся самой читалкой без аккаунта и токена.
Установленный через Setup комплект тоже поддерживает этот канал.

[Всегда актуальная страница установки и обновлений](https://github.com/mihailangel939-glitch/lector-pro-updates/releases/latest)

При повторной установке или удалении программы `Data` и неизвестные файлы
сохраняются. Перед установкой и удалением закройте читалку и завершите обновление.
Контрольные суммы SHA-256 находятся рядом с EXE; описание обновления подписано
Ed25519 и проверяется читалкой перед запуском обновлятора.

В репозитории размещаются только готовые файлы и инструкции. Исходники проекта
закрыты; здесь нет книг, личных настроек, токенов или ключа подписи.
